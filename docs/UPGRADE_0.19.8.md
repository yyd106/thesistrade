# 0.19.8：保护性执行、调度与撤权恢复

已有持仓变为风险警示股票后，原来的名称检查同时拦住买入和卖出。本版保留禁买规则，允许已有可卖持仓退出，继续核验交易时段、报价、T+1与近涨跌停条件。

动态买单在每次部分成交前重新核验完整准入。公告获取失败、新公司消息或覆盖过期时撤销余单并释放预留资金；三条执行线路在既有硬退出条件触发后也先撤销剩余买单，避免一边退出一边继续买入。限价单更优价格成交的含义不变。

主、动态和全球后台任务的完成对象统一回收。若最终状态暂时无法保存，后续循环只重试保存结果，不重复执行任务；启动或错误记录失败也不会终止整个调度循环。重启仍将未完成交易任务标为中断，不补追历史订单。

撤权通知的排队、合并和回执清理改为原子操作；每次新增通知带独立本地版本，旧回执不能清掉同时新到的通知。请求签名的时效与重放检查保持原样，允许离线期间累积的旧业务事件补送；已被更新研究覆盖的事件幂等确认，不把旧业务时间误认为过期请求。

无需改配置、迁移账本或改写历史。先云端、后本机部署，保留旧代码并完成十分钟同步核对。固定风控、资金、费用、模型和观察范围保持原值。
