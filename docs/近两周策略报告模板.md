# 近两周策略报告模板

该报告供管理员复核并向有权阅读研究的交易专家解释：研究了什么标的、根据什么证据作出判断、怎样形成程序计划、组合决定怎样使用该计划。模板只整理已留存数据，不生成新的研究判断，不修改生产研究提示词、交易规则或风控参数。

## 报告入口与文件

保留原四文件 ZIP 协议：

| 文件 | 用途 |
| --- | --- |
| 总览.md | 阅读入口、窗口内最后一次生成决定的标的索引、覆盖范围和导出缺口 |
| 研究策略.md | 研究评审、逐标的研究与交易方案、原有完整研究记录 |
| 交易策略变更.md | 每次生成/确认发布版本的变化、原始组合理由及来源引用 |
| 策略数据.json | 原始白名单投影、冻结来源及关联关系；协议不变 |

“近两周”指近14个北京时间自然日，含生成当日，截至报告生成时刻；不是每个交易计划都有效两周。每张卡须单独列研究/计划形成时间、数据截止时间、计划和组合有效期。形成时间不能代替资料截止时间。

## 最新方案与完整历史索引

每个标的、每条研究路线只展开最后一次组合决定引用的方案；没有组合决定时，展开最后一份留存研究。每份历史来源都保留短索引，列出来源编号、形成时间、冻结引用、对应组合次数及首末决策编号；全部研究版本、冻结投影和逐次组合理由仍完整保留在原始研究记录、交易策略变更与结构化数据中。详细卡只展开最后一次对应决定，避免研究复用和高频续签让报告重复放大。

这项排版去重不删除历史、截短原文或放宽96MB解压上限。以下为每份最新方案的固定结构。

### 一、覆盖范围与版本

- 股票/资产名称和代码，研究路线，来源记录编号，冻结引用。
- 原计划或研究形成时间；明确记录的研究依据截止时间；行情截至交易日。
- 关联公司研究编号和形成时间，计划有效期，原记录状态。
- 明确说明该卡是决策时冻结来源、导出时留存研究，还是历史来源缺失。

### 二、研究方案与分析依据

1. **研究问题、假设与判断**：记录的命题、可检验假设、研究倾向或方向、计划留存的研究依据。未单列明确假设时标记缺失，不把选股结果倒推成假设。
2. **证据、来源与取得时点**：事实引用、证据编号、关键证据的交易含义、明确关联的新闻标题/链接/发布时间/首次取得时间。只有编号的引用必须说明资料元数据缺失。
3. **分析推导与价格反映**：原始分析、事件冲击、业务传导、因果链、分维度分析、价格是否已反映、研究方法与约定。程序入场价格不是估值结论。
4. **催化观察、反证与核验计划**：研究成立条件、下次核验、待检验预测、反证、其他解释和研究失效条件。没有留存的内容明确缺失，不补写催化时间或收益预测。

### 三、程序交易规则

- 入场区间、止损价和止盈价，转换成人民币元或美元展示；原始字段仍完整保留。
- 计划仓位上限、计划类别、原公式与限制条件。
- 原记录中的止损/止盈参数、持有天数、复核间隔、报价基准时点。
- A股价格字段以分存储；全球资产价格以百万分之一美元存储。100基点等于1%。
- 未记录的价格、期限和参数不套用当前默认值。研究失效条件与程序已实现的卖出条件分开。

### 四、组合决定与交易对应

列出最后一次引用此冻结来源的决策编号、形成时间、动作、当前与目标仓位、单项上限、原始理由、组合证据编号、发布状态、来源和组合有效期、是否允许增加。窗口内的全部引用次数和首末编号在历史索引列出，逐次决定完整保留在交易策略变更与结构化数据中。

0.22.6起另列“条件归因与数字核对”：分析/发布快照的校验重放、原发布分支当场留下的收紧或目标重设编号、尚未记录的模型经济触发/终止归因。三者不能混为因果证明。数字诊断区分一致、与分析时数字不一致、旧记录疑似差异、有记录可解释的发布重设、无法核对；逐次提示与结构化比较保持对应，原文不改写。

报告现有白名单没有模拟成交明细，不能确认实际成交价、数量或盈亏。必须明确此限制，并以决策编号、来源计划编号和标的代码指向云端账本核对；发布成功不等于成交。未进入组合的研究保留研究卡，不虚构组合授权。

### 五、缺口与版本追溯

逐字段列出明确命题、证据、统一截止时点、价格反映、成立条件、反证、失效条件、后续核验和计划持有期的留存情况；“已留存”不代表研究充分或可执行。

保留原研究披露的缺失资料、策略版本、代码/模型版本、研究沿用关系。缺少版本时仅列可核对记录编号。

## 关联与保真规则

- 冻结来源必须与组合条目的路线、标的代码、来源编号相符，且来源形成时间不晚于组合决定；否则明确历史来源缺失。
- 公司研究只能按计划的 study_id 关联，且研究时间不晚于计划形成时间，并只取同一标的；不把其他股票的分析或后来的研究套入历史计划。
- 每个标的、每条路线只展开最新方案；同一研究复用产生的旧来源通过历史索引指向完整原始记录。导出时留存但未进入冻结组合的来源和独立公司/产业研究也进入索引，不能冒充已有组合授权。
- 没有冻结来源时不以当前研究替代历史；当前留存的原始记录仍在后半部供独立核对。
- 新闻元数据为导出时查询，不声称它在决策时已经完整冻结。
- 不读取模型输入、提示词、配置、原始资料路径、凭据或额外数据库表；不调用模型补全。
- 所有外部文字经过 Markdown/HTML 转义。保持固定文件名、结构化 JSON 协议、只读事务和容量上限。

## 验收

使用合成数据验证公司、事件、全球资产三条路线、价格单位、来源版本映射、缺失字段、未来/其他标的研究隔离、特殊字符转义与只读确定性；原导出、同步、下载权限和容量测试继续通过。不要用生产数据库作为测试夹具。

## 报告审计展示

本节新增确定性统计及程序发布回执展示，不改交易策略、研究提示词或执行阈值。统计保存于 `coverage.report_audit` 与 `coverage.guidance_summary`；旧版四文件协议和JSON顶层结构不变。

生产决定仍在 `payload.publication_audit` 留存完整发布回执。仅导出JSON时，将回执按决定编号集中保存于 `coverage.publication_audits`，对应组合使用 `payload.publication_audit_ref` 引用；同一决定同时作为两个比较基线时共用一份完整回执。此布局改善压缩效率，不删减审计字段或历史记录，不修改生产数据。读取器兼容旧内嵌回执与新集中索引；引用必须等于本组合的 `record.id`，缺失、错配或冲突明确报错，不借用其他决定的审计。96MB解压与14.5MB压缩上限不变。

### 计数与变化率

- **组合轮次**：一份组合决定计一轮。**标的项次**：一轮中一个路线/标的键计一项，同一股票跨轮或跨路线重复计数，不能作为独立投资样本。
- **已确认发布轮次的动作或主动目标变化占比**：分子是已确认发布且原比较标记为 `action_target_change` 的轮次，分母是全部已确认发布轮次。没有基线的轮次不能据此认定为无变化。
- **同键配对动作变化率**：分母是相邻生成轮次之间同键且两边动作可读的配对；窗口首轮使用窗口前生成基线。分子只数动作枚举改变。新加入、移出、缺基线或不可读项单列，不混入分母。
- ALLOW 按 `can_increase=true/false/未记录` 与 `qty>0/qty=0/不可判定` 交叉列数，保留原记录冲突。它们都是授权与资格统计，不能称为研究转交易率或成交率。
- 来源复用按“路线标的键、来源编号、source_token”去重；缺token单列。重复引用不等于新增研究，也不等于研究内容重复。

### 目标与发布时点

ALLOW、REDUCE、EXIT 是模型在硬约束内选择的主动动作。平台没有确定的研究评分阈值或“研究分数→主动目标”公式，不能从理由文字推导不存在的数字规则。总览列出的资格、区间、仓位、风险限制是合法性条件，不是模型必须选择某动作或某目标的充分条件。

前后为同一 HOLD/PAUSE 且两轮 `target_bps=current_bps` 的目标变化单列为占比随动；动作切换后进入 HOLD/PAUSE 的目标重设另列，避免把减仓结束误判为估值漂移。没有成交与估值流水时，不反推随动的具体原因。

新版发布回执逐项保留模型原动作/目标、分析时与发布时的占比和增加资格、两时点账户净值、校验状态及程序调整码。Markdown展示净值与持仓估值（人民币分），并按 `ceil(持仓估值×10000/max(1,净值))` 复算基点占比；全球路线的qty按每100,000,000单位对应1个实际资产单位解释，原始字段不修改。

审计字段分为完整、不完整、未留存或版本不支持。旧记录不回填模型原目标、不推断降级原因。历史理由始终保留原文；若文字与结构化数字冲突，实际授权动作和仓位以该版本的 `action/target_bps/current_bps` 为准；若发布审计自身与最终结构化项冲突，则显式提示人工核对。

### 规则与冻结缺口

研究指导表单独列累计留存、截至报告时点采纳/适用、窗口内新采纳和退役数量；仅此表为0不能解释为程序没有交易或风控规则，也不能代替全部已采纳提案数。原“已记录研究规则”数量仍是本档案选入版本数。

冻结记录存在与逐标的来源匹配分别计数。窗口缺口按已知版本明确记录的最早覆盖起点分为起点前遗留、起点后新增、起点未知；窗口前基线另计。首次成功冻结只作为观察时点展示，不单独证明此前尚未启用。快照中明确保留的覆盖起点也可作为分组证据；不将任意未知版本或空对象当作覆盖证明，不宣称期间连续完整。

历史缺口不删除，也不拿当前研究补写。该审计只串联到授权与发布，报告仍没有模拟成交明细，不能据此计算成交转化或收益归因。
