# 升级到 0.15.2

0.15.2 按用户 2026-09-26 的决定调整断网时的行为：现阶段研究不要求准时，本机不在线时等联网后再研究。运行日报随之区分“离线造成的延误”和“联网状态下的异常”。交易规则、研究提示词、模型和策略类设置都不变；硬性风控不变，云端 12 小时收不到新的组合决策仍会停止新买入。

## 改了什么

**断网时等联网后再研究**

判断依据是本机每分钟一次的云端账本同步：同步因本机无法联网而失败（域名解析失败、网络不可达），并且持续 3 分钟以上，就视为离线。云端返回错误（例如 502）说明本机网络正常，不算离线。

离线期间：

- 需要联网的任务留在队列里等待：资料研究、资料采集、研究、单股补齐、复盘、动态新闻、全球资产研究、组合决策。运行日报、评估打分、周报不需要联网，照常运行。
- 正在进行的资料研究在下一只股票开始前停下；动态新闻在下一个阶段开始前停下；研究失败后不再重试。已经研究完的股票保留新计划，其余股票沿用原计划。停下的任务记为“断网停止”（`DEFERRED`，错误信息以 `OFFLINE:` 开头），不算失败。

恢复联网后，调度器按原有逻辑补做最近一轮资料研究、全球资产研究、动态新闻和复盘，研究结论变化后照常触发组合决策。

这样改是因为 0.15.1 之前，断网时资料研究仍按时开始，每个来源都要等到超时，一轮研究拖到 4–8 小时，其间组合决策一直排队；恢复联网时如果这轮研究还在运行，调度器也不会再补做研究。9 月 24 日、25 日两晚的资料研究分别跑了 460 分钟和 247 分钟。

**记录离线和停顿**

- 离线：同步恢复时，把这次离线的起止时间写入 `ashare-data/workflow/service/offline.jsonl`（持续 2 分钟以上的才记）。
- 停顿：调度器两次运行相隔 5 分钟以上（电脑睡眠或服务停止），把起止时间写入 `ashare-data/workflow/service/pauses.jsonl`。

两份记录从 0.15.2 上线起才有；此前的日子，日报里显示“没有断网或停顿记录”。

**运行日报**

新增“本机在线”一节，列出当天每次断网、停顿的起止时间和合计小时数，以及断网时停止、联网后重做的任务。其他各节和“需要关注”的规则调整如下：

| 规则 | 0.15.1 | 0.15.2 |
|---|---|---|
| 抓取失败率 | 全天失败占 20% 以上 | 只统计联网期间的采集尝试 |
| 资料研究任务未完成 | 包括推迟 | 不含断网停止 |
| 资料研究耗时（新增） | — | 联网状态下超过 2 小时，研究期间组合决策排队 |
| 研究模型调用失败 | 失败不少于 3 次，或占 30% 以上 | 联网期间失败不少于 5 次，且占 10% 以上。原来的百分比规则按“失败”状态计数，而研究失败实际记为“推迟”，所以从未生效；原来的 3 次门槛几乎每天都触发 |
| 组合策略发布间隔 | 最长间隔不少于 3 小时，只给小时数 | 写明起止时间和其中离线或停顿的小时数；联网状态下空档不少于 3 小时才列出；任何空档超过 12 小时都列出，因为云端这时已停止新买入 |
| 当天复盘未成功 | 复盘不是成功或无需分析 | 复盘时间本机离线或停顿的，写“联网后补做” |
| 策略类设置被修改 | 同一设置改几次列几次 | 每项只列一次 |
| 服务曾中断或断网 | 列入需要关注 | 移到“本机在线”一节 |

另外：组合策略一节同时列出组合决策任务的结果和失败原因（同步占用、断网、其他）；研究一节的模型统计改称“当前计划所用模型”；任务表和资料类型不再出现英文代号。区间汇总的逐日表增加“离线 / 停顿”一列，最长间隔后注明其中离线或停顿的小时数。

## 兼容性与部署顺序

数据库结构和云端协议都不变。云端不运行日报和研究，这次的改动只在本机生效；为了两端代码指纹一致，仍按惯例先云端、后本机：

1. **云端**：合并到 `main`，Railway 自动部署。
2. **本机**：用旧代码停服务，同步新代码，再用新代码安装服务（`update-local.sh`）。

代码指纹变化，升级后第一轮研究全部重新调用模型。

## 本机设置

不需要修改任何设置。

## 部署后验收

- [ ] 云端 `/health` 返回 `version` 0.15.2，`code` 与本机 `./agent doctor` 的 `build.code` 一致。
- [ ] `./agent digest --date <当天>` 的日报有“本机在线”一节。
- [ ] 下一次断网或睡眠之后：`workflow/service/` 下出现 `offline.jsonl` 或 `pauses.jsonl`，当天日报列出起止时间；断网期间没有新开始的资料研究，联网后补做了一轮。
