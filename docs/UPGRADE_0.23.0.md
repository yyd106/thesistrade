# 0.23.0 手工股票名单与盘前研究

## 范围与时间

启用时沿用研究端已经保存的 22 只 A 股及其只研究限制。首批美股为 AMZN、HPQ、INTC、NVDA、TSLA、MRVL、TSM。TSM 对应在纽约交易的台积电存托股份。管理员以后可在固定关注名单中手动调整，美股上限 10 只。模拟账户继续管理移出名单的已有持仓、退出和交易账本。

按上海时区和已维护的 A 股交易日历运行。开市日 08:00、12:00、20:00 开始，休市日仅 20:00。日程限定公司研究和组合更新，成交检查、风险退出与复盘有各自的时段。早间先完成 A 股并发布，云端须在 09:25 前接收当轮组合才能记作盘前准点。美股研究随后进行，晨间组合暂停美股新增买入，午间完整复核后可重新授权。研究机失联或 A 股晨间组合缺席时，旧授权不能在次日开市时新增买入。

## 两周留存

主程序新增只读清单 `./agent maintenance --research-retention plan`。`research_retention_enabled` 默认关闭。实际清理须先核对清单、受保护依赖及不可恢复的影响，经独立批准后启用。检查镜像文件与原库快照到期凭证的数量和逻辑字节，另行列出仍被交易、去重、复盘和 20 交易日评估引用的材料。保留现金、逐笔成交和待结判断。历史原始材料、影子账本所需策略与旧备份仍需分别核对。

导出器独立于主仓部署，交付目录为同一 Mac 项目下的 `optimize-20261126/export-service/`。其 README 包含内容寻址安装、回滚、900 秒调度和现有 STOP 的处理。启用股票名单不改变导出器的安装状态，也不解除 STOP。回滚程序不能恢复已经实际删除的数据。
