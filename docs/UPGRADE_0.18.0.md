# 0.18.0：最小前向实验运行器

已有实验设计停留在 DESIGNED。本版增加明确启动、实时入组、两臂订阅调用、失败恢复、固定截止和安全摘要，先支持一个候选：自选股研究中的结构化可核验失效条件。

## 实际比较什么

两臂都使用现有研究提示词、同一份冻结资料和同一输出格式。基线也可以输出有效条件或 UNKNOWN，候选只多一条固定的明确反证检查要求。程序验证条件是否含具体命题、指标口径、有限阈值、运算符、未来期限和给定原文引用。字段存在本身不计成功。

主要指标沿用 `verifiable_prediction_rate`，页面称“可检验结构比例”。这是单轮输出质量实验；两臂共享生产已有历史，候选答案不会成为下一轮生产记忆。引文逐字匹配也不证明引用足以支撑阈值，更不证明经营预测兑现或交易收益。

## 冻结与采样

- 显式启动时冻结当前完整代码/策略配置/模型/已采纳规则版本、候选文本、共同schema、评分器、窗口、预算及股票范围。旧设计基线不一致或不在首期白名单时拒绝启动；需另登记当前版本，不修改旧设计。
- 默认先观察50个自然日、隔离40日、再确认50日。实际启动时间决定两个半开窗口；`start_after`仍只是最早允许启动时间。不得中途修改标准、延长观察或择优重开同一实验。
- 总计至少30对，每窗至少15对，至少30个日期簇；日期簇仍不保证独立。每天最多2对，每窗最多60次调用，整个实验最多120次，含失败、超时、中断和重试。每臂最多重试2次；成功、UNKNOWN或校验失败的有效返回都不择优重跑。
- 只从启动后的新研究快照入组，必须在生成后60秒内登记且尚无研究结果。生产续期、历史补登记、手动旧资料重演不入组。
- 以本公司本轮新证据对应的来源家族为目标，同一目标事件及修订整个实验只占位一次；共同底稿可以保留为上下文。可检验条件必须引用本次目标证据。按自然日每股最多一对，采用先到的新目标事件，结果不参与抽样。
- 两臂输入完全相同，以配对ID固定交替调用顺序，不让一臂读取另一臂结果。冻结输入超过6小时或窗口已结束即保留失败，不在以后补跑。

## 失败与结论

每次调用先在数据库占位，重启也计入预算；中断可恢复，单臂成功后不重复调用。异常只向调度状态写错误类别。原始输入、输出和调用文件仅在本机实验目录与数据库保留，网页和监督摘要只接收允许的程序统计。

未完成、失败和UNKNOWN都保留在已登记配对分母。页面分别展示两窗口的计数、比例、差值和引用率；少于30日期簇不提供区间。固定截止前不作成功判定。结束时先检查样本与完整性，不足为INCONCLUSIVE；足够时只作结构指标的描述比较：确认窗未改善或引用率下降则不支持候选，否则仅表示观察到结构比例提高。无PASSED、自动批准或自动采纳路径。

实现版本、模型、配置、名单或已采纳规则改变时保守结束为INCONCLUSIVE；保留所有记录，不悄悄替换基线。研究与监督任务优先，实验会取消当前订阅进程让位；离线和禁用模型时不调用。调度每60秒推进截止，日报评估也执行同一无模型检查。

## 命令与入口

在本机运行目录使用：

```bash
./agent experiments prepare
./agent experiments start EX-编号 --note "Dean 2026-10-03 要求先验证一个候选、一个主要变化"
./agent experiments list
./agent experiments show EX-编号
./agent experiments advance
./agent experiments run EX-编号
./agent experiments close EX-编号 --to CANCELLED --note "关闭原因"
```

`prepare`仅登记完整DRAFT及冻结设计；`start`明确启动隔离实验但不改变提案审批状态。日常调用和截止由服务自动处理；`run`只处理已经实时入组的下一配对，不能生成旧输入。观察结果在「交易与复盘 → 改进提案」展开查看。

本轮不实现收益类候选、多路线或多候选运行器、5日评分、自动采纳。生产提示词仅提取纯函数，逐字保持原样；本轮提示变化只存在于隔离实验。新增表全部追加并有不可修改/删除触发器。按运行手册先云端、后本机部署，回退保留数据库和实验记录。
