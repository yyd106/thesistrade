# 0.19.1：复盘与新闻内容有效性

复盘区补齐程序检查与发现去向，分开24小时核算、48小时回看及模型意见，标注持仓损益不含分红。当前待处理事项优先，旧结论与失效审查折叠保留。

新闻以摘要呈现待跟进与历史研究，显示复核和结束时点、初稿与独立评估方向、修订摘要。历史使用相同代表事件去重，注明加载范围。观察测量跳过已完成项目，避免最早600条记录阻塞新观察。

原评分和5日辅助诊断保留原口径，增加统计覆盖期，并按真实时间选择最近版本。上述内容不自动进入生产研究或批准。

部署先云端后本机。配置、账本、原复盘、原评分、提案和实验历史保留。完整代码指纹变化会使旧前向实验按原规则结束；同候选在新版本独立冻结，不合并样本。验收记录见本轮迭代规格及本地上线笔记。
