# 0.19.6：盈亏对账与报价来源说明

账户概览与历史复盘原先展示不同时间、不同节点的报价，且只解释持仓损益不含分红，没有列出历史累计分红。买入成交行还统一写成“尚未卖出”，即使后续已卖出。

本版补充只读展示：

- 账户概览显示累计现金分红；复盘分列24小时分红、截止累计分红、成交与持仓累计损益、含分红账户累计损益。
- 用冻结复盘估值与截止前流水核对账户金额，并与当前账户分解浮动、已实现和分红变化。只有持仓份额、成本均可核对一致且已实现未变时才称“报价快照差”；其余明确为持仓变化或待核对差额。
- 历史报价按证券、价格、报价时间、已知时间匹配来源，展示供应商时间与系统首次取得时间。晚于15:00不等于盘后成交或已核验的交易所收盘价；旧记录缺证据时明确未知。
- 买入成交行说明“买入不结算已实现盈亏”，卖出行继续展示原账本已实现盈亏。
- 云端兼容旧版签名页面摘要，补充只读对账；新增摘要字段通过既有白名单同步。

不修改原复盘、成交、资金流水、研究提示词、交易规则、观察名单或审批状态，无数据库迁移。按运行手册先云端后本机部署。程序版本仍按既有完整Python代码指纹归因，前向实验继续遵守既有版本冻结规则。

验收：合成用例覆盖历史分红但当期零分红、报价差、已清仓成交、缺失来源、截止后流水、提款及不能解释的资金差额；完整Python与UI回归，以及真实浏览器排版检查。
