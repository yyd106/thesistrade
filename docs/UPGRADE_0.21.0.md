# 0.21.0：模拟利润提取闭环

Dean 于 2026-10-11 确认采用[利润提取方案](iterations/模拟利润提取闭环方案.md)的三项规则。本版在云端模拟账户增加按档位维护的提取周期、管理员冻结预览与确认、原子记账和精确对账；研究端只显示同步摘要。

## 操作行为

- 严格超过当前档阈值才触发；执行端每60秒复核，成交前再次复核。跌回阈值或以下暂停未完成部分，重新越线后生成新预览。取消未发生部分保留已发生流水，不推进档位；取消后的同档等待先回落、再重新越线。
- 跨档跳涨只处理当前档；完成后重新估值，最多前进一档。提取金额按最新净资产减留存目标计算。
- 管理员在“持仓与收益”核对具体模拟金额并确认。估值、现金、持仓、委托或相关风险状态变化会使旧预览失效；重复请求不重复记账。
- 现金不足、报价不足、存在未知委托或提取后违反现有仓位约束时等待。不会为凑现金自动卖股，不接真实转账。
- 无自动对账容差；结果未知先只读核对，不猜测成功或重复执行。记录不一致保持复核和停买状态。
- 已知未成交买单在提取期间撤销，三条执行路线在资金事务内重新检查。日报区分资产变化、模拟提取及资金流调整后的投资损益；提取不解除回撤锁定。

## 升级与回退

按先云端、后本机的既有部署流程执行。新周期、预览和事件使用新增表，旧资金流水及旧提取记录保留；新摘要只在研究端明确请求后通过同步附加字段发送，旧节点的基础账本表清单不变。提款预览不通过旧版治理通知通道下发。

曾使用本版提取或取消后，不能仅因数据库可读就降级到缺少新周期状态机的旧执行版本。回退前暂停新的提取确认并核对所有周期、预览、未决结果和旧表兼容状态；保留资金流水及审批记录，禁止恢复覆盖账本或重放已完成提取。

完整验收包括边界金额、回撤/重新越线、跨档、旧预览、权限、并发/重试、资金守恒、单位净值、风险约束、研究副本只读和旧节点同步兼容；最终结果另记本地部署验收笔记。
