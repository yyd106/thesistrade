# 0.21.1：普通 A 股个人账户红利税

持有享受过现金分红的股票并卖出后，旧版本保留税前分红却不补扣红利税，模拟收益因此偏高。用户于2026-10-12明确确认采用普通A股个人账户口径，并补齐历史已卖股份的红利税。本版在云端追加可追溯的税款流水，现金、累计收益和报告同步反映已扣税；原始成交、分红凭证和冻结复盘不改写。

## 计算口径

- 只针对自选股路线已经实际记入 `CASH_DIVIDEND` 的纯现金分红。税基采用原分红凭证的每股税前金额，登记日收盘持股决定权益。
- 按每日日终结算后的净增减股份形成税务持股批次，并按先入先出确定持有期。同日卖出又买回的抵消部分不当作净减持扣税。税务批次只决定分红税，不改成交成本分配。
- 普通自然人股东持有一个月以内（含一个月）适用20%，一个月以上至一年（含一年）适用10%，超过一年免税。自然月、年及精确边界在测试中明确；不能确定的边界拒绝自动入账并留下错误，不能猜一个税率。
- 按分红事件、减持日与税档计算，四舍五入到分。盘中不永久扣当日税，收盘后的定时任务完成日净减持核算；执行端也会在成交事务中核对应补的已结算日期。
- 已卖出后才补收到分红，或升级前已经发生的减持，也参与重放；没有40日回看截断。尚未卖出的股份不预扣未来税款。

依据：[财税〔2012〕85号](https://www.chinatax.gov.cn/chinatax/n810341/n810765/n812151/201211/c1082457/content.html)、[财税〔2015〕101号](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)、[税务部门2015年政策问答](https://shanghai.chinatax.gov.cn/zcfw/zcjd/201509/t419000.html)及[中国结算登记结算数据接口规范（结算参与人版V3.95）](https://www.chinaclear.cn/zdjs/jshsc/202502/143bfe0cd2084f49bedc7f3d5f81788b/files/登记结算数据接口规范（结算参与人版V3.95）.pdf)。本系统执行模拟账务，不向税务机关申报缴款。

## 记账与展示

新增资金流水类型 `DIVIDEND_TAX`，金额为负数；唯一凭证绑定规则版本、原分红和减持日期。税款与现金扣减在同一资金事务中完成。重试和并发不能重复扣税；历史事实矛盾、已有税款不符或现金不足时整体回滚并报告，不能制造负现金或无凭证扣款。

补记采用实际入账时间，凭证保留原减持日期；过去已生成的成交、净值、复盘与日报保持原样。税款是投资费用，不是资金提取，不注销本金份额，不计入已提取金额。

账户页增加累计已扣红利税与分红净入账；复盘区分成交与持仓损益、税前分红、已扣红利税及账户净收益。跨日补税在归因桥梁中单列，不能被标为来历不明差额或扣两遍。旧版冻结记录没有新字段时保留未知信息，不伪造历史已扣税。

`./agent dividends` 仍为只读命令，新增税款历史、应补金额和累计已扣金额。研究副本不记税；沿现有增量账本同步 `paper_flows` 与账户现金。

## 发布与核验

按运行手册先云端、后本机。上线后执行端定时核对会追加已有历史欠税。用只读税款预览、现金重放、唯一凭证数量及两端账本摘要核验实际补记。不得手工改数据库以“凑平”余额。

验证覆盖：20/10/0税档与边界、日内净额、分红权益、部分减持、多个分红、分位舍入、晚到分红、幂等并发、资金不足回滚、研究端禁写、跨日补扣和报表守恒；完整测试结果见本次发布验收记录。

本次未扩大动态或全球路线的分红支持，没有处理送转、配股、差异化分红，也不声称完整复制某家券商的全部收费项目。审计发现的同日成交成本排序与并发快照问题不混入本次税款规则变更。

## 回退

税款使用既有资金流水表，已入账金额不可随代码回退删除、回灌或重新增加现金。退回不支持税款展示的版本会漏列分项且停止未来自动补税，因此优先以前向修复处理；确需回退先核对全部已扣凭证、现金和未结算税务日，不以覆盖数据库恢复。
