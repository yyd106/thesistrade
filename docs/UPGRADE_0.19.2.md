# 0.19.2：页面摘要独立同步

补齐0.19.1上线核验发现的时效性缺口：复盘和新闻展示摘要原先依赖每日复盘或下一次组合发布，云端可能继续显示旧分类和旧去向。

现在通过独立的签名展示通道同步有界复盘与新闻摘要。它不触发模型研究，不发布策略，不改变交易账本，也不刷新12小时研究授权。旧记录保持原样，较旧摘要不能覆盖更新摘要。

先云端后本机部署，按功能声明兼容旧节点；新字段不混入原监督摘要的1MB预算。完整验收和实验版本迁移记入本地上线笔记。

复盘至多5期、1MB；新闻每类至多60条、总计8MB；长字段最多1800字符，含截短提示。总数、载入数及状态核对时点明确显示，原始完整记录保留在本机。云端验证展示字段和摘要哈希，重复提交幂等；失败独立记录并保留上次成功展示。

验证：770项Python测试，769通过、1项既有环境跳过；全套UI测试通过。新增11项独立同步测试覆盖旧节点兼容、无交易授权续期、失败隔离、乱序保护、字段边界和真实数量。另用合成数据验证47处新闻/复盘关键字段能经独立摘要在实际前端渲染。
