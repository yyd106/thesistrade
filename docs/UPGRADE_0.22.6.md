# 0.22.6：条件目录、发布命中与仓位数字诊断

2026-10-25 用户明确批准实施条件目录、真实程序命中记录、数字一致性报警以及管理员报告集成。工程问题为 `7f86c4c3ce66cb8d4d770648`。本版只增加旁路审计和报告诊断，保持模型输入、提示词、输出协议、动作与定仓规则、执行条件和审批机制不变。

## 三种记录分别解释

- **程序检查**：有版本的条件目录，使用该决定分析/发布两个时点已保存的快照重放原校验谓词，区分通过、不通过、无法判断、不适用。合法性通过不等于模型必须买入或减仓。
- **程序实际命中**：在原发布分支进入时追加编号，证明本次程序确实暂停新增、保持仓位或重设被动目标。没有同期分支记录时保持未记录，不能从重放结果反推实际执行。
- **模型经济归因**：原模型没有输出触发/终止条件编号，本版继续标明未记录。条件编号完整不等于主动目标可以由经济规则唯一推导；没有新增自动失效卖出规则。

条件目录与已批准研究指导分开计数。执行时的行情、现金、心跳、价格区间和成交不在本回执覆盖范围；发布校验不能冒充成交核对。目标清零沿用 EXIT，REDUCE 保留正仓位。目录没有新增仓位档位或偏离带。

## 数字报警与误报控制

管理员导出时进行确定性的只读诊断，核对明确的当前仓位、目标仓位和减仓百分点。百分比与百分点分开处理，按原文显示精度处理舍入；经营利润率、价格收益、上限、假设及不清晰措辞不能强行解释成仓位。

新记录可对照分析时当前仓位与模型原目标；缺少该时点的旧记录只能标疑似差异。有完整发布重设依据的 HOLD/PAUSE 差异单列解释。未识别或无法可靠比较时保留未知。诊断附原文位置、角色、比较字段及数值，原文、结构化目标与历史记录不修改，报警不阻断交易。

## 固定报告与权限

四文件 ZIP 协议、管理员下载权限和访客白名单保持不变。总览新增条件覆盖、命中统计、数字诊断统计及条件目录；逐标的研究卡展开检查；交易变更文件保留每轮提示。结构化摘要及数字比较保存在 `coverage.condition_audit`；同期条件回执随原发布审计保存，仍使用 `coverage.publication_audits` 集中布局。

为容纳完整两周窗口，导出中的相同条件回执按规范 JSON 内容的 SHA-256 无损去重，保存在 `coverage.condition_receipts`，逐标的 `condition_audit_ref` 指向该内容。读取时验证内容摘要、引用存在性与双格式一致性再展开；缺失或冲突不借用其他回执。生产记录仍内嵌保存。四文件、历史内容与96MB解压/14.5MB压缩限制不变。

证据引用和关联项目分别统计原列表变化与集合成员变化；来源变化单独列示。相邻同键配对包含窗口前基线，新增/移出不纳入这些字段比较。字段变化不能证明新增事实、有效研究或独立机会。

## 验收与边界

验收覆盖真实发布分支与语义不变、旧/新签名包、审计异常降级、损坏字段、访客隔离、数值角色和精度、历史不改写、完整窗口容量以及全量测试。保留全部应用代码进入现有保守研究行为指纹的机制，不为避免旧实验身份失配而扩大排除名单。

新同期回执从部署后的自然决定开始累积；不会补写历史。旧报告可重新导出获得带明确标记的事后数字诊断，但这不新增当时证据。规则收益验证、5%/10%/15%档位和一个财报季旁路实验需要独立冻结设计，本版不自动启动或批准。
