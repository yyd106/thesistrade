# 0.22.10：D14 熊市门槛与 P06 成本价回撤锁

两端代码同时支持 D14/P06，两个配置默认均关闭。R1 原请求不执行；未启用时市场徽标只描述状态，明确模拟账户仍按总仓 90%、单只 20% 和原买入条件运行。

D14 沿用 R1 两日确认市场状态。偏多/震荡维持90%/20%；偏空或缺失/过期数据限制新买为总仓50%、单只10%，计划同一日线最近20个对数收益的样本标准差按√244年化后不得超过37%。缺失波动拒绝新买。组合判断、云端策略接收、下单和未成交买单结算均重新核对当前状态。已有单只超过10%只禁加仓。偏空总仓超过55%在下一交易日开盘开始按比例减至50%；55%仅是启动门槛，已开始回合不会在54%提前结束。数据过期不触发市场状态减仓。

P06 复用权威 portfolio_risk 的现金流单位化净值u，B初始1，F=0.9B。仓位预算 max(0,min(90%,10×(u−F)/u)) 向下取整到基点；锁阈值按精确数值判断，日终预算≤10%上锁，盘中直接跌破底线则立即上锁。估值不完整保留成本状态并禁止新增买入。锁定后额度只降不升、撤未成交买单，三路线都停买。成本减仓与市场状态共用一个持久回合，P06不额外放宽5个百分点。T+1、交易时段、停牌、跌停和整手规则仍优先，无法成交不保证达到目标或亏损上限。

P06 新买预算随完整净值实时收紧；常规减仓只使用上一完整日终成本上限，从下一交易日开盘生效。盘中新预算继续下降不会提前压低已有减仓回合目标；跌破成本底线的零上限例外仍立即生效。

云端管理员在“成本价回撤锁”中生成预览、核对旧基准/当前单位净值/硬停后确认重置。COST_BASIS_RESET审批一次性使用，过期拒绝，按执行瞬间u设置新基准，记录旧/新基准、时间、AR及回执哈希。重置不解除25%硬停；硬停状态的改变也不会解除成本锁。未知提交结果先只读核对，不自动重复提交。反复重置会建立新成本基准，累计相对最初投入的亏损仍可能超过10%。

成本锁和基准版本变化会重新触发组合研究；单纯风险轮询与连续预算变动不会额外触发模型。风险轮询也不会让内容未变的利润提取预览过期，真实成本状态变动仍须重新预览。A股列表与单股页、全球资产列表及动态卡片都按查看端当前规则显示等待原因，保留原始研究结论；持仓加仓提示不超过当前单只上限。

## 上线与启用

1. 先云端、后研究端部署并核对两项关闭时行为。D14须云端exposure_caps_v2配对，P06须cost_budget_v1；新旧端不单侧启用。
2. 核对当时权威仓位、挂单、市场状态、u、估值完整性和成本预算。
3. 每次只改一个键：先申请并确认 exposure_regime=D14，核对生效bundle/页面/首周期；再申请并确认 cost_budget=P06，分别留AR与实施证据。不能把部署写成启用。
4. 回退经原生单键配置审批设为null。禁用保留已存成本锁和基准；重新启用沿用原状态，不自动重置。待新策略发布后核对云端OFF。

第七单的comparison_series索引和存储调度修正同版本整合，单独测试记录见本轮执行回执。

## 验证边界

离线回测是机械规则和有幸存者偏差股票池的探索证据；E6原报告使用横截面S2，不能将其结果直接当作37% S2a生产策略收益。实际生产还包括研究、组合、成交约束和现金流账本，逐日市场状态一致不等于逐笔交易或收益一致。新联合复算另行固定登记、脚本和结果；不承诺相对最初本金累计亏损或从峰值回撤≤10%。
