# 工作台连接提示与读取性能修复（0.4.3）

## 用户问题
首页显示“暂时无法连接”，但外网正常，更新时间一直停留在读取中。

## 查证
- 本机服务仍在运行。2026-09-21 00:54:51（北京时间）上一轮研究完成，22 只股票均已有成功研究。
- 检查到的旧浏览器页签收到 401“请先登录”。旧页面把这类返回与请求超时、渲染异常、任务进度读取失败统一显示为无法连接。没有证据证明截图当次一定属于其中哪一种。
- 服务日志存在向已断开的客户端写入数据时的 BrokenPipeError；该记录只能证明客户端已停止接收，不能单独证明外网故障。
- 当前数据测量：完整状态 2,287,831 字节，生成约 3.04 秒。主要耗时为逐股检查新闻时按文档读取正文，缺少索引而重复全表扫描。

## 修复
- 登录失效、连接失败、请求/正文读取超时、后台异常、页面显示异常分别提示。登录失效返回登录页，并保留明确的登录入口。
- 首次读取失败不再一直显示“读取中”；恢复后自动更新。首次会话查询失败也会重试。
- 单个任务进度读取失败只影响对应的进度提示，首页已成功读取的数据仍可查看。
- 为正文添加文档编号、段落顺序索引，兼容既有数据库。
- 首页状态仅传输首页所需的研究摘要与复盘统计；个股页仍提供完整研究、证据和维度分析。数据原文、历史研究与交易条件均未改写。
- 已断开的客户端不再尝试接收第二条错误响应。

## 验证
- 当前 22 只股票数据：优化后状态生成 0.10–0.14 秒，响应 586,790 字节（约减少 74%）。此为本机数据处理测量，不代表任何网络的固定响应时间。
- 回归覆盖 401、503、非 JSON、请求和正文阶段超时、渲染异常、断连后恢复、任务状态故障隔离，以及首页精简后个股证据完整性、旧数据库新增索引和客户端中止。
- Python 158 项测试和全部前端回归通过；4 个并发首页请求在隔离副本中分别约 0.53–0.55 秒完成，Guest 管理任务信息仍被隐藏。
- 正式服务已重启并返回版本 0.4.3；没有中断运行中的研究任务。
- 浏览器实测：测试服务断连后重连；测试登录失效后跳转登录页；重新登录后首页恢复 22 只股票和最新研究时间。
