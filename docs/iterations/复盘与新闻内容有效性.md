# 本轮：复盘与新闻内容有效性

状态：0.19.3隔离补强实现与回归通过；两端上线及观察结果见本地策略隔离核验笔记

目标：交易者能从近期复盘、新闻研究中看清事实、尚待验证的判断和下一步证据；页面不会随历史积累持续变长。

范围：交易与复盘、新闻与事件的展示和只读摘要；额外观察仅在页面辅助计算。保留原始历史，展示诊断不成为研究证据；不修改研究提示词、交易规则、观察名单、评分口径或审批。
