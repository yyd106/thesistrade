# ThesisTrade：个股详情与朋友协作

状态：已完成（2026-09-18，0.4.0）。仅本地调试，不创建远程仓库，不部署Railway，不改变网络监听范围或交易规则。

| 编号 | 需求与边界 | 验收 |
| --- | --- | --- |
| P1 | 首页列出全部自选股、模拟持仓状态、最新报价时点、买入区间、卖出参考和止损、当前行动判断；点击进入独立个股URL | 列表与详情同源；过期价位明确标示；不虚构卖出区间 |
| P2 | 每股展示完整可翻页成交/委托/决策历史；最新研究按经营、现金流、估值、价格、事件风险、交易条件固定维度展开 | 不混入其他股票；已有研究按原文分组并注明；新研究输出固定维度及来源；不额外生成第二套交易价位 |
| P3 | 个股显示当前持仓、关键变化、有效期、论点失效条件、资料缺口、待办和原文 | 不把旧结论或失败结果冒充最新成功研究；保留后续处理安排 |

| P5 | 首页及个股右栏意见板，登录用户均可提交；管理员私有页按股票/状态查看和处理 | 留言绑定页面与研究版本；Guest及未登录者不能列出任何意见；不自动修改策略或进入模型证据 |
| P6 | 项目暂名ThesisTrade，未来再确认远程名称及部署方案 | 本轮仅本地代码、测试、运行与设置说明；密码/会话/意见/研究数据不进入未来源码仓库 |

用户已确认Guest只读＋提交意见。工作假设：意见状态为待看/处理中/已采纳/暂不采纳；昵称可选，Guest共享账号不代表独立个人身份。卖出参考只有一个现行策略价位，直接显示该价格；不存在的区间不补造。

## 验收结果

- P1–P3：浏览器验证7只自选股首页、美的集团独立页面、六个分项、缺口与下一步、空成交提示及历史决策；数据库测试验证36条跨页记录无重复、无串股。原价位及交易条件沿用。独立六维模型输出的格式和引用校验通过；旧报告标注整理来源，下一次研究按新结构生成，未为UI改动额外发起全量模型研究。
- P4：首次设置、Guest与Admin登录、退出实际验证；自动测试覆盖未登录拦截、越权访问、限速、会话过期/撤销、改密、CSRF和来源校验。密码由用户在正式页面自行设置，无默认密码。
- P5：独立数据副本中通过Guest提交个股意见，Admin读取、修改处理状态、保存备注，刷新后保留；重复提交去重，意见不进入研究或任务队列。正式意见表仍为空。
- P6：全套Python测试142项及现有JS界面测试通过，实际页面验收完成。0.4.0服务重启并恢复心跳；保留79份已有研究、原有7只自选股、10万元模拟账户。升级前数据库备份在数据目录backups/before-thesistrade-0.4.0.sqlite3。GitHub/Railway未部署，监听范围仍仅本机。

登录、密码恢复及协作说明见 [COLLABORATION.md](../COLLABORATION.md)。后续对外部署需另行落实HTTPS、安全会话、持久化数据与Mac Mini任务同步。
