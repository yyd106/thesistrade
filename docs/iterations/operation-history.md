# 仅记录买卖操作与明确当前执行状态（0.5.1）

Dean要求每分钟没有操作就不保存交易记录；同时指出页面一直显示等待复核，无法判断是否需要重新研究。

## 记录规则

- 操作指实际提交模拟委托或发生成交。HOLD、资金不足、已有未结束委托、行情/公告未通过检查等均不新增历史买卖记录。
- `latest_trade_checks` 每股一行，覆盖最近检查时间、动作、结果及原因，供首页、个股页和待办归口使用。
- 提交委托时，交易依据、对应股票的当时输入与委托在同一数据库事务中提交；被拒绝或事务失败不会留下孤立的买卖记录。其他无操作股票不进入该轮完整输入存档。
- 无操作不写完整Slot输入文件；任务结果不保存逐股无操作列表。保留基本调度和Slot完成标记，用于去重、断点恢复以及禁止离线补旧单。
- 已有委托的后续部分成交仍独立保存，即使这一分钟没有提交新委托。旧数据不物理清理，页面与新复盘只选择关联实际委托的依据；以前生成的复盘保留原统计口径。
- 新复盘明确采用“仅操作”口径。无买卖记录不等于没有检查，不能推断无操作频率、错过机会或虚构经验。
