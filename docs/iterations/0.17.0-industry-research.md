# 0.17.0 产业链研究与双名单

状态：实现完成，发布验收记录见下文；生产上线结果另记工作区部署笔记。对应已批准提案 `ffe28ef2465b4be3`。需求来源为工作区 `docs/design/产业链研究与双名单.md`；本文记录实现约束、验证和部署，不另设一套需求。

## 目的与已确认范围

让研究从固定股票扩展到有证据支持的名单外公司，保留现有公司研究、统一组合、模拟执行及硬风控。首批方法为 1 二级供应链、2 扩张瓶颈、3 资本开支顺序、8 政策到实际采购，五个领域为 AI 算力、电力能源、机器人自动化、半导体设备材料与先进封装、医疗设备及医院采购。

Dean 已确认固定名单移出海天味业、顺丰控股、福耀玻璃，保留其余 19 只。正常容量为固定股票 19＋固定资产 4＋动态最多 17＝40。动态名额与原宏观发现共用。已持仓和 OPEN/PARTIAL/UNKNOWN 委托继续管理；移出名单不自动卖出。

## 实现

- `industry.py`：追加事实、供应关系、指标、项目标包节点、假设版本、经营预测与结果。事实区分原文披露、指引与估计，保存引文、时间、质量与文档版本。相同原文不刷新催化时钟。预算、招标、中标、合同、交付、验收、付款独立保留，不累加为订单收入。
- `industry_sources.py`：巨潮行业关键词发现与限量正文采集；政府采购公开入口及覆盖台账。受限制的采购源冷却六小时，不将抓取失败当成零事件。
- `industry_research.py`：现有订阅模型按五领域检查四方法，证券身份来自已有中美公开目录；原文不足留在线索层。每个领域保存检查点，没有变化的输入可复用，未处理领域下轮优先。
- `universe.py`：固定、动态、待复核及受保护对象统一查询。复用已有动态分配与替换门槛，不另建第二套资产额度。A 股统一进入财报、公告、行情、公司研究；美股补 SEC 财务底稿和披露，缺资料不新增买入。
- 组合与执行：名单指纹纳入组合依赖，公司计划与最新名单依据不一致时停买。动态 A 股使用原公司研究执行路线；历史短期案例继续管理，禁止同股从两条路线重复新开。
- 同步：签名发布包带 `industry_lists_v1` 资格，校验固定配置、身份、额度、证据引用及期限。撤销先落库再发送，失败由一分钟同步重试；撤销和重发不延长 12 小时研究心跳。
- 页面：固定 Watchlist / Dynamic List / 全部观察，支持假设原文、反证、缺口、下一节点、名单历史及经营验证展开。股票价格评分与经营预测结果分开。

## 数据与预算

原文仍使用本机内容哈希文件；SQLite 保存结构化版本。Railway 接收必要摘要、引用摘录及签名资格。当前没有配置 OSS、创建云存储资源或上传本地原始档案。若以后需要远端档案，OSS 的公网 HTTPS endpoint 可供 Railway 调用；私有 endpoint 不能直接当公网入口，仍需另外配置权限及实际连通验收。

`industry_enabled` 默认为 false，已批准生产配置启用。`industry_policy` 可配置发现预算、公司阶段总预算、单源预算、查询天数、单页数量、正文份数及每领域假设数。默认分别为 600 秒、3000 秒、90 秒、14 天、20 条、2 份、8 条；50 分钟之后为组合发布留出时间。正在执行的单个请求受自身超时约束，因此这是调度预算，不是精确墙钟保证。采集与研究以已完成公司/领域为检查点，断网后优先补未完成对象。

收入情景只对原文参数、期间及量纲匹配的区间作 Decimal 运算；缺少新增量、单位用量、单价或份额就显示缺口。经营预测冻结基线、区间、单位、期间、到期日；后续无可比披露记 UNKNOWN，冲突记 CONFLICT，不把它们判为失败。自动实验运行器不在本次声称已完成的功能内。
