# 0.20.0：可积累的诊断证据与资产研究要求

长期自检读取截至检查时点已冻结、且结果已经可用的全部历史。先按路线与持有期限选择入场日期批次：同日标的全部保留，下一批必须晚于上一批最晚退出日；选择后重新做时间聚类，再按版本、环境和行动分组。原30簇门槛保留，每日滚动观察仍保留重叠。补到的历史评分可能改变新报告采样，因此这属于观察性诊断，不称为前向预注册或独立样本。

新自检方法为`selfcheck-v2`，采样为`entry-date-cohort-v1`；既有评分算法不变，旧报告不改写。追加提案证据的身份包含方法、完整分组统计、引用集合和冻结评分，既覆盖相同判断改用新方法，也覆盖其他组变化使本组样本收缩。相同完整快照不重复追加，各版本不能相加。原候选命名空间保留，方法升级不会重新创建已经拒绝的候选。

已有提案的证据刷新与生成新候选的门槛分开：样本减少、均值转正或整个适用范围降为零也会更新；零样本明确显示，不沿用历史统计。快照变化后又回到原值时保留新的追加节点，只对连续相同快照去重。新链接按追加顺序校验完整范围与前一节点，不更改原提案状态或v1记录。

完整部署身份继续用于审计。新前向实验设计增加`research-behavior-v1`身份：默认包含应用Python、静态资料、依赖声明、配置、已采纳规则、运行时与模型执行文件；只排除经核验的三份纯展示模块以及发布版本字面量。资料处理、选择、提示词、模型、测量或策略变化仍不兼容。新自选研究复用采用同一身份，并继续核验资料、价格和时效。旧实验与旧研究保持原完整build约束，不迁移样本、不恢复已终止实验，不自动启动实验。服务端同名模型的不可见内部变化无法由本地指纹保证冻结。

全球研究按资产类型区分必要证据：公司股票保留公司基本面与正式披露要求；黄金、白银、BTC、ETH不再因没有公司财报而被提示强制等待。它们只根据已提供的量价与相应事件研究，缺失宏观、供需、链上或资金流数据明确列为未知。价格历史只证明量价观察；证据不足仍WAIT，不强迫产生LONG。新合同标为`asset-evidence-v2`，进入研究方法身份与保存的输入、输出。
