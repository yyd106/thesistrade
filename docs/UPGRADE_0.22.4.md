# 0.22.4：逐标的策略报告与研究访问保护

## 用户请求与范围

2026-10-24 用户要求将“近两周策略”整理为其他交易专家可核查的研究方案和交易策略模板，并对所有非管理员隐藏跟踪理由与研究摘要、产业研究进度与资料来源、组合策略、待处理事项、候补与归档。此次改变报告展示和读取权限，不修改研究提示词、交易规则、仓位参数、观察名单、执行流程或账本。

## 报告

保留原四文件 ZIP 和 JSON 同步协议。总览提供逐标的报告阅读顺序；研究策略按股票/资产列研究问题、证据、分析推导、反证、执行规则、组合决定及对应版本。历史策略只使用对应冻结来源；缺少依据、有效期或成交记录时如实说明，不用新研究补写旧判断。完整记录继续供追溯。

## 访问边界

- 管理员页面与后台信息保持完整，管理员下载包含完整模板和研究材料。
- 非管理员保留入选标的、行情、参考价位、结果状态、持仓与成交/委托结果。
- 首页和个股接口使用嵌套字段白名单；无角色和未知角色不能获得管理员研究权限。
- 原文、归档分页、快照、检索、完整报告下载由服务端限制为管理员；归档个股接口拒绝访客访问。
- 隐藏相同研究信息的重复入口，包括个股依据、全球资产研究详情、新闻研究、复盘研究分析、改进提案、监督材料及成交原因。已有模拟成交金额仍显示。
- 不依靠折叠面板或 CSS 保护数据；浏览器刷新、切换市场和直接接口请求均受相同边界限制。

## 验证与上线

隔离测试覆盖完整敏感数据投影、本机与云端接口、未知角色、管理员原样读取、归档访问、文档预览和下载权限；UI 检查覆盖角色、刷新、切换和直接调用。完整测试与部署结果留存在本次工作记录。

部署顺序为云端先、本机后。保留原配置、数据与回退代码；部署通过健康检查和管理员页面确认后再更新本机服务。历史程序记录不改写，模板通过下一次正常导出生成。
