# 0.19.7：恢复产业发现后的动态新闻任务

产业研究可以先于宏观事件发现标的。原先这些标的只有产业依据，没有宏观观察身份记录；动态任务保存观察池状态时触发外键约束，导致后续新闻筛选、事件研究和影响评估中断。

本版在保存观察池状态的同一事务中补齐缺失的研究身份，覆盖活跃及归档项；已有身份记录保持不变。不创建宏观事件，不改变固定观察名单、准入条件、额度、证据期限或交易规则。纯产业标的再次读取时保留产业适配器的展示状态及证据时间，避免身份持久化被误认为宏观研究结果。

无需手工修表或重写历史任务。下一次动态任务会通过正常流程完成身份注册，并保留既有失败记录。外键约束保持开启。部署按运行手册先云端、后本机，验收至少包含完整动态任务、后续研究及影响评估、策略发布与账本同步。

代码指纹随修复改变；隔离实验继续遵循原有版本一致性检查，不能修改冻结基线或拼接不同版本样本。资料来源的扫描件文字不足、超时等独立缺口仍由原补齐与限制机制处理。
