## 1 两项独立服务

| 需求 | 对应产品 | 所需条件 |
| --- | --- | --- |
| 行情、历史价格、财务、估值及资讯数据 | Choice 数据量化接口 / EMQuantAPI | Choice API 数据权限；具体字段、资讯和研报全文覆盖须按套餐确认 |
| 个人证券账户的资金、持仓、委托和成交；后续真实买卖 | 东方财富证券 EMT 等获准交易接口 | 券商确认个人账户适用产品、开通条件及接入权限 |

用户提供的 [Choice AI 指南](https://quantapi.eastmoney.com/AIGuide/PromotionPage?from=web) 是数据接口的 AI 接入入口。官方提供 SDK 和 Skill 安装指引；安装 Skill 不能代替数据授权，也不能开通证券交易权限。普通东方财富证券账户不代表已经开通上述两项服务。

[Choice Python 手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_Python.html) 中的 `pcreate / porder / preport` 属于组合管理函数。其参数包括自定初始资金、历史交易日期与价格等；据此不能把“组合下单”当作本人证券账户的真实委托通道。本项目不会使用这些函数接管证券账户。

## 2 先接 Choice 数据

### Dean 需要完成的步骤

1. 打开 [Choice 官网](https://quantapi.eastmoney.com/)，使用自己的 Choice 账号登录；如果只有证券账户，先申请试用或咨询开通。官网提示联系客户经理或 **400-620-1818** 开通量化接口权限。
2. 明确申请的是 **Choice 数据量化 API**。询问 A 股和科创板的日线、盘中报价、财务、估值、公司公告、新闻及券商研报全文各自的覆盖、限额、延迟和费用。确认自动定时采集、本地存储及将许可内容交给云端模型研究的使用范围。没有公开确认的套餐价格，本项目不假定免费。
3. 在官网“账户名 → 个人资料”绑定手机号，或者在 Choice 金融终端“用户中心 → 资料管理”绑定。安装匹配版本 SDK 后，由 Dean 在官方激活工具中输入手机号和验证码，生成本机登录令牌；不用把验证码或密码交给研究模型。
4. 首次只验证少量自选股的日线、报价及一个财务字段，核对数据和权限，再加入定时采集。SDK 安装和激活具体步骤以 [官方安装指南](https://quantapi.eastmoney.com/AIGuide/Install?from=web) 与 Python 手册为准。

可直接向 Choice 客服说明：

> 我在 Apple Silicon Mac 上运行个人 A 股研究程序，关注主板和科创板，每天抓取两次资料、盘中每半小时检查行情。想申请 Choice 数据量化 API 试用。请确认数据覆盖、研报/新闻正文权限、调用限额和费用，以及本地存储和云端 AI 分析权限，并提供适配的 Python SDK 和激活方法。

### 本机兼容性

本机为 `arm64`。截至核查日，[官方下载中心](https://quantapi.eastmoney.com/Download?from=web) 的 Python 包和 Mac C++ 包版本为 **2.7.5.0**。已只读下载并检查 Mac C++ 包，其中核心库和激活工具都包含 `x86_64` 与 `arm64` 两种架构，说明官方现有 Mac 原生组件覆盖 Apple Silicon。

这只是二进制架构核验；尚未验证 Python 包加载、动态依赖、激活和实际取数。Python SDK 仍须在项目独立环境中验收，不能把架构通过写成已接通。官方手册提示 Mac 图形激活工具需要 GTK 3 环境。暂不需要因此购买另一台 Mac。

核验包：`https://cftdlcdn.eastmoney.com/Choice/EMQuantAPI/EMQuantAPI_CPP_Mac.zip`；本次下载 SHA256：`004c9148df6837fded3b1bf679bc7116185a2e00d527968fe5190ad3fa9140ed`。这是本次下载记录，不是厂商发布的可信签名。

### 接入现有工作流的方式（待实现）

- 在采集层增加 Choice 适配器，由一个独立数据进程管理 SDK 登录、请求排队、限频、超时和重连，避免研究与盘面检查各自反复登录。
- 内部自选股继续用 `sh600519 / sz000333 / sh688062`；适配器转换为 Choice 的 `600519.SH / 000333.SZ / 688062.SH`。用户不必修改 watchlist 的证券标识规则。
- 行情与财务作为结构化事实入库：保留证券、指标、数值、单位、币种、报告期、发布时间、取得时间、实际可用时间、来源及修订版本。复权方式单独记录，缺失值不能补成零。价格计划不混用不同复权口径。
- 新闻、公告和有权限的研报保留原文及文件哈希，沿用按证券、实际可用时间、版本和使用许可过滤的研究快照与检索。行情数字从数据库读取；正文依据从原文检索。后来的财报修订不得覆盖历史决策使用的版本。
- 每项取数和处理接入现有 `data_attempts`：缺失权限、连接失败或解析失败出现在对应股票底部；只有同一来源、股票、具体资料/处理项后续成功才清除。服务级故障可作用于全部股票，正常“无新资料”不记失败。
- Choice 接入可以补充研究依据；它不会自动改变目前的技术模拟价位规则，也不能替代尚未完成的财报审阅。新策略应独立定义和验收。

## 3 再接东方财富证券账户

[EMT 官方申请页面](https://emt.eastmoneysec.com/apply) 的“交易终端与服务 → 仿真”提供“API 测试申请”；页面另有程序化交易相关办理入口。个人账户能否开通、门槛和收费必须由券商确认，不能从测试入口或其他产品的资产要求推断。

[官方交易软件下载页](https://emt.eastmoneysec.com/down) 当前列出：EMT API **2.27.0** 支持 **Windows/Linux 64**；东财掘金独立端支持 **Windows**。当前公开下载项未列原生 macOS EMT SDK。若券商提供的版本仍如此，Mac 继续运行研究与工作台，交易连接端放到券商支持的系统；CPU 架构、部署环境和网络白名单需一起确认，不能假设 Apple Silicon 上的任意虚拟机就兼容。

[EMT 2.27.0 官方 FAQ](https://emt.eastmoneysec.com/api/help/md_input_2EMTAPI__FAQ.html) 明确实盘登录涉及客户机 IP 白名单。其当前 API 认证描述不同于普通客户端的密码登录，因此接入必须使用券商发给该账户的连接地址、账户标识及认证说明，不能复用手机 App 登录请求。

### 账户适配器接入顺序（待实现）

1. 仿真环境验证 SDK、登录、查询、断线恢复；普通手机账户登录成功不代表 API 已开通。
2. 正式账户只查询：同步资产、现金、持仓、可卖数量、委托和成交；与官方客户端逐项对账。账户数据与现有模拟账本分开，页面必须显示账户类型、同步时间和异常状态。
3. 仿真环境验证委托、撤单、分批成交和重复回报；订单未知状态先查询核对，不能直接重发。跨交易日重新建立会话并对账。
4. 实盘执行作为后续独立交付。先确认策略管理的资金/持仓范围，再落实初始 10 万元及已确认的利润提取阶梯。未被策略管理的其他个人资产不能被错误纳入卖出或提取计算。科创板等规则仍须单独实现并按账户权限校验。

## 4 凭据如何存放

Choice 激活令牌由官方 SDK 按其目录结构保存并限制本机文件权限；后续适配器只读取必要配置。证券连接参数、权限及认证资料按券商实际方案处理。密码、验证码和令牌不进入普通配置、数据库证据、日志、代码仓库或模型提示词。

目前无需新建 `.env`，也没有需要填写的虚构 API Key。真正需要 Dean 完成的是确认服务权限、官方登录/激活及必要的券商手续。确认接口和认证方式后，才能给出有效的凭据写入步骤。
