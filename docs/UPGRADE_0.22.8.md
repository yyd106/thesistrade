# 0.22.8 候选：SEC 安全来源、只研究隔离与月度待决清单

本地可审候选，尚未获代码审批、部署或启用任何配置。本批整合 A4 安全客户端、A6 只研究能力和 P11 月度首页；不实施 A3 门控，不写入私人联系方式，不变更观察名单，也不更新交易日历。

## SEC 来源

默认 `sec_enabled=false`，同时暂停 SEC 公司数据与监管 RSS。缺有效联系方式、未显式启用或云端角色均不发 SEC 请求。保留的旧资料不冒充新采集成功；缺资料明确标识暂停或联系方式待补，不计为成功抓取零条。非 SEC 来源按原规则运行。

SEC 请求只在研究节点由专用客户端访问 HTTPS 的两个官方主机；User-Agent 携带私有配置中的联系方式。统一共享每个数据目录的限速和冷却状态；实际请求间隔至少 0.5 秒，403/429 至少冷却 60 秒并尊重更长 Retry-After，重定向、重试也计入。限制无法跨机器或不同数据目录共享，因此正式启用只允许一个研究节点。

联系方式只作私有身份，不进入快照、构建身份、通用错误或缓存正文；拒绝来源响应反射联系方式。配置只展示是否已设置。通用配置写入仍禁止该字段，本版没有安全的私有联系方式写入入口，不能通过手改配置、命令行明文或普通配置日志绕过。默认暂停仅在代码获准部署后生效，不能把候选默认值当作生产已暂停。

## 只研究能力

观察标的可设严格布尔值 `research_only=true`，研究、参考价位、登记及评分保留；缺价格保持空值。对应研究计划不进入可交易门槛分母或组合候选。固定、动态及全局账户的委托创建和执行均检查配置与持久禁止交易锁，旧计划和旧授权也不能绕过。两种行业开关路径、签名成员和有效行为身份均覆盖只研究状态。

持久锁不会因删除标志、普通账本导入、失败重试或恢复而解除。未来解除须另行批准，本版无解除入口。启用前必须无任何相关持仓、敞口或未终结委托；未知订单状态也拒绝。否则不启用，以保护已有持仓的硬退出。禁止绕过配置事务直接改标志；该做法可能冻结已有持仓的退出。

A 账仍是原规则的纯反事实评估，不创建账户委托；B/C/D 不因 RESEARCH_ONLY 生成新入场。历史计划、门槛统计与独立评估标准不按当前名单改写。工程测试通过不证明收益有效。

### 启用与回退顺序

本候选只交付能力；双端最终权威预检与精确配置审批尚未完成，不启用名单标志。正式启用必须另获授权，并按以下顺序：

1. 停止旧执行器，确认双端运行理解持久锁的新代码。云端检查所有相关账户、敞口和未终结委托，失败或未知即停止。
2. 云端先通过受审事务落持久锁；完成全量账本同步并核对版本。本机检查云端能力、匹配账本版本及 120 秒内的云端预检，再检查本地账户。
3. 本机后应用精确名单配置审批。事务失败保留锁；不得通过重试、删标志或恢复旧配置重开交易。
4. 故障回退保持停止或交易隔离，保存锁与数据。旧二进制不识别持久锁，不能直接回退到旧执行器继续交易；任何解除或恢复交易需单独批准。

## 月度首页

自 2026-12-05 起，每月第一个周六的前一日运行日报首页列出生成时的全部 READY 待决项，并分列 DRAFT 与 APPROVED 数量。历史补生成不倒填今天的队列，读取失败显示未知，不显示为零。清单只读，不自动批准、驳回、实施提案或建立额外提醒。

## 名单变更提交检查清单（A5）

以下是后续名单配置的提交要求，本版不启用候选：

- 每个新增、删除或只研究状态变更同时提交 `comparison_peers`、`business_keywords`、`research_topics` 与各项选择理由；说明受影响对象和未知项。
- 主标的与可比标的采用相同价格口径，逐项核对双方 20/60 交易日窗口和当前 `as_of`；窗口不足、停牌、缺价格或日期不一致如实保留，不伪造补齐或统计结论。
- 只研究状态变更必须核验云端和本机敞口、持仓与未终结委托；遵守云端先锁、本机后配置顺序，提交绑定精确差异的配置审批。
- 三只新股的精确候选独立待审；迈威的参考配置延后，不因本文发布而默认采用。
