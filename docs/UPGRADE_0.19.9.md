# 0.19.9：开盘时序与历史授权证据

日线对照和离线回测先处理已经发生的开盘触发，再处理无法确定先后的盘中高低点。如果开盘已经高于止盈价，随后盘中低点穿过止损价，不再把这笔退出倒置为止损；仅盘中同时触发两者时，仍使用原有先止损的保守假设。上一交易日已确定的趋势退出也按开盘执行。

影子组合逐项核验开盘时点的研究来源、完整版本和关联依赖；最新组合过期后不会退回更老组合。历史上已被替代的研究按照当时状态判断，不使用今天的状态冒充过去。缺少可证明的来源记录会显示“历史证据不足”及原因，不能解释为模型观望或有效授权。

新组合保存供本地评价使用的来源快照和变更记录。历史可见性按已提交的观察记录界定，跨越开盘的提交时间不明确时保守记为不足。该辅助记录不改变生产组合、持仓或交易规则，也不回填旧组合的证据。

影子方法为`opening-evidence-v3`，使用独立运行指纹与当前指针；保留原影子交易、旧指针、冻结报告及评分。离线回测带新方法标记并保留已有输出。

本轮不扩展日线模型到“开盘部分减仓后同日再退出”的多次成交模拟；该模型边界单独保留，不据此声称对照账本等同逐分钟执行。

macOS服务安装固定使用`~/Library/Logs/ThesisTrade`，避免重装时覆盖原可用日志目的地而启动失败；只有安装时创建目录，创建失败不停止旧服务，原日志保留。该恢复修复源于第一批部署现场核验。
