# 0.22.2：管理员下载近两周策略

用户要求在管理员登录后下载近两周研究与交易策略，并能核对交易策略如何变化、为什么变化。首页增加“下载近两周策略”，访客和未登录请求均不能读取下载接口。

## 下载内容与时间口径

下载ZIP包含总览、研究策略、交易策略变更及结构化策略数据。范围为含今天在内的14个北京时间自然日，截止时间是文件内注明的生成时点。导出保存研究原文结论、失效条件和待核验事项，以及每次组合决策的动作、目标仓位、当时理由和组合总结。

变化比较使用窗口开始前最后一份组合决策作为基准；没有基准时明确标注。动作和目标调整、仅理由变化、来源变化、持仓估值变化及有效期续签分别说明。缺少原始记录时标明未知，不用当前研究填补历史，也不把组合目标当作实际成交。未确认云端接收的本机决策与已发布决策保持区别。

## 数据与权限边界

历史研究在本机以一致性只读事务导出。字段采用允许清单，不读取配置凭据、原始文件或模型输入。云端现有执行表不能完整保留本机每次研究，因此下载档案通过独立签名通路同步到专用缓存，不向执行表补写历史。

后台使用独立工作线程，最多每5分钟生成和同步一次，不占用研究、账本或页面摘要线程。云端只接受已签名的固定格式ZIP，校验哈希、文件名、条目、解压大小和时间范围；旧包不能覆盖新包。下载缓存未就绪或已跨北京时间日期时返回可重试提示。

管理员下载接口使用现有登录、同源检查和禁止缓存响应；访客返回403，未登录返回401。前端等待期间防止重复点击，读取失败不会将错误响应保存成ZIP。此功能不调用模型，不更新研究完成时间，不续签交易授权，不改风控或下单规则。

## 验证与发布

测试覆盖时间窗口、窗口前基准、重复时间、策略变化分类、原始理由保留、缺失及损坏记录、字段过滤、只读导出、签名后的接收边界、缓存时效、管理员权限及后台隔离。发布前运行完整Python测试和所有网页测试，并在本机只读生成实际档案核对大小、覆盖范围与可读内容。

按既有流程先云端后本机；旧本机不会使用新通路，新本机仅在云端声明支持后启用。回退代码不影响账本，新建下载缓存独立于研究和执行状态。只读下载功能失败时保留既有研究与交易流程。
