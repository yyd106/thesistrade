# 升级到 0.15.8：审计缺陷修复

用户于 2026-09-30 要求根据独立审视报告修复。本版修复 F1–F7 及动态复盘入场依据漂移；不采纳报告中的候选交易策略，不改变模型、资产范围、交易阈值或硬性风控。

## 行为变化

| 问题 | 修复后的行为 |
|---|---|
| F1 判断尚未生成就开始计收益 | A 股评分只使用判断完成后、且晚于数据基准日的首个开盘；09:30 同时完成也顺延。缺入场日或窗口内行情继续等待，不跳过缺价日。基准缺价允许补齐后重试。 |
| F2 对照时序失真 | 09:30 前已生效的研究和组合授权才能参与当日回放；盘中到期的授权只允许开盘即在买入区间内的成交。开盘现金和仓位额度冻结，当日卖出不补充买入额度，也不当日卖出再买回。 |
| F3 缺价被当成完整账本 | 检查全部观察标的当日行情及前 60 个交易日历史，首个缺口起暂停。报告明确 WAITING_DATA / PARTIAL、完整计算截止日和缺口。补数或修订后完整重算所有依赖日期，产生新批次，保留旧批次。 |
| F4 相关样本及混合版本被高估 | 全部可评分样本先统一去重，再分组和分 build。名称改为“不重叠样本”，跨标的重叠窗口归入同一时间簇；不足 30 簇不给近似区间。监督校验禁止用混合 build、不同全球持有期或不足时间簇判定有效性。 |
| F5 全球回测趋势窗口错位 | 生产和回测共用纯函数，MA20 包含最近一个完整日观测，动量比较生产既有的倒数第 5 个观测。回测从恰有 20 条历史时即可开始。 |
| F6 全球缓存忽略版本和采纳规则 | 缓存身份包含代码、策略配置、模型、采纳规则、行情、事件及方法。更改任一有效输入重新研究；完全相同输入仍复用，不延长原到期时间。 |
| F7 复盘遗漏动态与全球成交 | 三路均核验价格上界、原始准入、组合授权、回撤停买及卖出理由，逐路线给出覆盖数。无适用成交为 NOT_APPLICABLE，缺原始引用为 INSUFFICIENT；缺证汇总为一个工程问题，避免多项检查重复登记。 |
| 动态入场依据被后来研究覆盖 | 复盘从已成交买单 terms 快照提取最初分析和计划；新委托另存准入状态及阻挡项，旧快照缺准入证据时如实标注不足，不反推。 |

三路新委托保存当时是否启用组合策略，避免用今天的配置判断过去的委托。回撤核验比较成交时间与触发时间，触发前提交、触发后成交的买单也会被发现。

## 记录和迁移

- 增量新增 `signal_scores`、`shadow_evaluations`、`shadow_days_v2`、`shadow_trades_v2`；原 `signal_registry` 中的旧评分和原影子账本不更新、不删除。
- 当前评分方法 `decision-time-v2`；对照方法 `opening-evidence-v2`。默认统计只读新方法。旧程序回退后仍可读旧表。
- 对照批次按输入内容寻址；事务完整提交后才更新当前批次指针，中断不发布半本账。相同输入不重复写入。行情补齐后的新批次与旧批次均可追溯。
- 日评估、周报另存 `workflow/evaluation/decision-time-v2/`，文件名含内容标识；原文件保留。报告仓库沿用已授权摘要备份，新增同名方法子目录。
- 原冻结评估批次、监督结论、日报不回写。修正效果应通过新评估和新报告查看。

升级后执行 `./agent evaluate` 与 `./agent weekly-report` 即可生成新口径结果，不调用研究模型，不修改执行账本。不手工补价格，不手改数据库。

## 解释边界

对照仍是日线层级的研究实验，不是执行账本的精确复制；未模拟盘中授权更新、12 小时心跳、账户回撤停机及公司行为。缺少确证停牌数据时等待。股票池或实验参数变化会形成新输入版本；其结果不能与旧版本直接拼接。

时间簇采用连接的重叠窗口，十分保守：连续滚动预测可能长期只有一个簇，届时只报告描述性统计。30 簇只是最低门槛；近似区间不证明因果、无过拟合或未来盈利。有效性实验仍需预先规定窗口和版本。

全球预测评分为美元收盘诊断，LONG 与 WAIT 可能持有期不同，不作直接优劣判断。全球离线回测的金银是期货代理，未计人民币汇率和最低佣金，持有期按日观测而生产按自然时间；报告明确这些差异。

按既定流程完整运行 Python 单元测试及 Node UI 测试后提交、推送和合并；先核对 Railway `/health`，再停止本机旧服务、备份纯代码、更新运行副本并重新安装服务。保留配置、凭据、虚拟环境及全部数据。部署后执行 doctor、model-check、status，并在十分钟后确认同步。

回退使用对应提交的 git revert，并先云后本机更新代码；不要恢复覆盖数据库，不删除新表、新结果或旧评估。
