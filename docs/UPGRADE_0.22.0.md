# 0.22.0：策略新鲜度与金银研究依据

用户于2026-10-15批准实施复核后的 W1、W3。本版分两次提交，便于分别核对与回退；没有纳入外部评审中的策略路由、复盘治理或统计评分改造。

## W1：准确显示策略新鲜度

账户页与运行日报增加独立诊断。四个时间维度分别解释：

- **研究依据年龄**：从成功研究完成记录计算。自选股计划续签不使旧研究变年轻；未做成的研究保留未知。
- **计划签发年龄**：从该计划签发时间计算，与底层研究年龄并列。
- **云端研究租约**：以云端实际接收的组合完成时间为准，12小时上限不变。页面在云端实时计算剩余时间；历史中断不等于本机离线。
- **本机在线**：沿用本机在线记录，不能用进程在线代替研究及时。

近24小时和7日统计采用实际经过的秒数，时间标注采用北京时间。每个接收凭证覆盖 `[received_at, completed_at+12h)`，重叠区间取并集，不能从完成时间提前计算云端可用。已有全部云端凭证可提供历史覆盖；本地只使用明确同步过的覆盖范围。覆盖不足时先标注整窗未知，并另列已知部分的中断次数、总时长及最长时长，不将缺数据解释为零中断。

三条路线分别列出计划有效数量、到期但数据库仍标为活动的数量、剩余期限及签发/研究年龄。这里的“时间有效”仅表示时间范围有效，不代表已通过行情、组合额度、交易时段等买入检查。自选股另列超过现行最大计划年龄的数量。无法回放的历史计划状态显示未知，不套用今天的 ACTIVE 状态。

近7日成交按买入、一般卖出、保护退出和未知分组，统计每笔成交发生时的计划/研究年龄；各组互斥。组合减仓属于一般卖出。迟于统计截止才入账的成交不回填当时统计；缺少来源计划的年龄保留未知。副本统计注明账本观察截止时间。

### 同步与隔离

云端通过已有账本附加信息回传有限的接收序号与时间（8日窗口加前序凭证，最多12,000条），不传研究正文。本地计算固定结构聚合，通过独立签名端点回传页面；仅含固定枚举、时间和有界数字，拒绝额外字段与自由文本。历史镜像失败只回滚该附加信息，展示失败不阻断账本和策略同步。

展示请求不会写策略凭证、研究心跳、合同、成交或资金记录，也不能延长买入授权。云端缓存超过3分钟标记为旧快照，同时继续显示实时租约。旧节点不认识新能力时跳过；首次接入未取得历史时显示等待或未知。

`strategy_freshness_enabled` 默认 `true`，属于运行类开关。关闭后停止统计、发送关闭状态并隐藏展示，不删除已有记录。再次启用恢复正常更新。纯诊断模块与该开关不进入研究行为指纹；完整发布代码指纹仍变化，混合模块没有被整模块排除。

## 发布和回退

先通过隔离完整测试，再发布云端；核对健康接口后停止本机旧服务、保存旧代码并更新运行副本，保留配置、虚拟环境及全部数据。新表仅追加诊断凭证，没有改写历史研究、交易或日报。W1 可关闭展示或撤销对应提交；不能通过删除数据库记录回退。

测试覆盖租约并集与边界、未知覆盖、续签年龄、保护退出分类、历史查询、只读执行、固定字段校验、丢失回执、重复/乱序传输、失败隔离和旧节点兼容；最终数量与部署结果记录在本次验收笔记。
