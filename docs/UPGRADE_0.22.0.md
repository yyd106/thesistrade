# 0.22.0：策略新鲜度与金银研究依据

用户于2026-10-15批准实施复核后的 W1、W3。本版分两次提交，便于分别核对与回退；没有纳入外部评审中的策略路由、复盘治理或统计评分改造。

## W1：准确显示策略新鲜度

账户页与运行日报增加独立诊断。四个时间维度分别解释：

- **研究依据年龄**：从成功研究完成记录计算。自选股计划续签不使旧研究变年轻；未做成的研究保留未知。
- **计划签发年龄**：从该计划签发时间计算，与底层研究年龄并列。
- **云端研究租约**：以云端实际接收的组合完成时间为准，12小时上限不变。页面在云端实时计算剩余时间；历史中断不等于本机离线。
- **本机在线**：沿用本机在线记录，不能用进程在线代替研究及时。

近24小时和7日统计采用实际经过的秒数，时间标注采用北京时间。每个接收凭证覆盖 `[received_at, completed_at+12h)`，重叠区间取并集，不能从完成时间提前计算云端可用。已有全部云端凭证可提供历史覆盖；本地只使用明确同步过的覆盖范围。覆盖不足时先标注整窗未知，并另列已知部分的中断次数、总时长及最长时长，不将缺数据解释为零中断。

三条路线分别列出计划有效数量、到期但数据库仍标为活动的数量、剩余期限及签发/研究年龄。这里的“时间有效”仅表示时间范围有效，不代表已通过行情、组合额度、交易时段等买入检查。自选股另列超过现行最大计划年龄的数量。无法回放的历史计划状态显示未知，不套用今天的 ACTIVE 状态。

近7日成交按买入、一般卖出、保护退出和未知分组，统计每笔成交发生时的计划/研究年龄；各组互斥。组合减仓属于一般卖出。迟于统计截止才入账的成交不回填当时统计；缺少来源计划的年龄保留未知。副本统计注明账本观察截止时间。

### 同步与隔离

云端通过已有账本附加信息回传有限的接收序号与时间（8日窗口加前序凭证，最多12,000条），不传研究正文。本地计算固定结构聚合，通过独立签名端点回传页面；仅含固定枚举、时间和有界数字，拒绝额外字段与自由文本。历史镜像失败只回滚该附加信息，展示失败不阻断账本和策略同步。

展示请求不会写策略凭证、研究心跳、合同、成交或资金记录，也不能延长买入授权。云端缓存超过3分钟标记为旧快照，同时继续显示实时租约。旧节点不认识新能力时跳过；首次接入未取得历史时显示等待或未知。

`strategy_freshness_enabled` 默认 `true`，属于运行类开关。关闭后停止统计、发送关闭状态并隐藏展示，不删除已有记录。再次启用恢复正常更新。纯诊断模块与该开关不进入研究行为指纹；完整发布代码指纹仍变化，混合模块没有被整模块排除。

## W3：补齐贵金属研究的三项宏观依据

金银研究复用现有 FRED 采集能力，加入名义10年国债收益率 `DGS10`、10年 TIPS 实际收益率 `DFII10` 和广义贸易加权美元指数 `DTWEXBGS`。新增的 `US10Y_REAL` 属利率类，原始单位为百分比。美元指标不是 DXY；利率是收益率，不是国债价格。

只在 GOLD/SILVER 研究前按需刷新这三项，沿用六小时缓存、每次最多五个序列的采集上限。不增加云端模型或宏观采集任务。BTC/ETH 的研究包和原提示要求保持原结构。三项输入冻结在本地 `input.json`，原计划生成及仓位约束保持不变；模型获得新事实后，判断可能变化，因此 W3 属研究输入变更，不保证收益提升。

每项保留观测日期、实际取得时间、此数据版本首次取得时间、来源网址和可引用证据编号。最新值与21个非缺失点构成20期变化窗口；利率差转换为bp，美元指数计算百分比变化，不能把20个自然日与20个观测期间混用。点数不够时变化量为未知；缺失、过期、抓取失败或缓存格式损坏时因子为未知，不拿旧值补齐，也不阻断其他资产的研究。

新鲜度按来源发布规律计算：[H.15](https://www.federalreserve.gov/releases/h15/) 工作日16:15美东发布前日观测；[H.10](https://www.federalreserve.gov/releases/h10/) 通常每周一16:15美东发布前一周数据，节假日顺延。本地政策考虑常规美国节假日，再容忍一个发布工作日的FRED入库延迟；这不是数据供应商的时效保证，特殊停发无法推定，超过期限降级为未知。

重新抓取相同数据不会使研究依据变新。内容指纹包含有效观测窗口、版本及可用状态，排除轮询时间；数据变化、修订或从可用转为过期等变化会触发重新研究。只有本次 READY 因子的证据编号可被模型引用；事实与资产涨跌的因果解释仍须分开。旧缓存注明原采集时间口径，不能冒充精确接收时间；旧研究快照不回写，也没有用今日FRED数据重建历史版本。

`global_macro_context_enabled` 默认 `true`，本次启用依据为用户对 W3 的明确实施授权。此开关属于策略类设置，并进入研究身份指纹；后续在线修改仍走现有管理员确认流程。关闭后恢复金银原研究包、提示要求及专门预取行为，不删除已有记录。新增序列仍在共用资产目录中，普通宏观采集器仍可使用它；关闭不等于禁用整个 FRED 能力。

## 发布和回退

先通过隔离完整测试，再发布云端；核对健康接口后停止本机旧服务、保存旧代码并更新运行副本，保留配置、虚拟环境及全部数据。新表仅追加诊断凭证，没有改写历史研究、交易或日报。W1 可关闭展示或撤销对应提交；不能通过删除数据库记录回退。

W3 可通过策略开关停用新输入，或撤销对应提交；历史输入、已发布计划和成交保留，关闭不会追溯撤销既有决策。紧急操作仍按既有运行及管理员确认流程执行。

测试覆盖租约并集与边界、未知覆盖、续签年龄、保护退出分类、历史查询、只读执行、固定字段校验、丢失回执、重复/乱序传输、失败隔离和旧节点兼容；W3覆盖发布周期、节假日、取得时间、负实际利率、单位换算、缺失/损坏/断网降级、内容指纹、合法证据及关闭回退。每个阶段都跑完整测试，最终数量与部署结果记录在本次验收笔记。
