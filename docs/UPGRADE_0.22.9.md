# 0.22.9 第四轮整合候选

本版本整合 trader-view、storage-budget、P01a r3、P02 r4、P07/P08 r2、P01d r2、P01e r2；包含独立复核发现问题的修补。验收及上线状态以本机第四轮回执为准，本说明不代表已经部署。

## 行为变化

- 今日操作的买入提示通过只读检查，与模拟委托共用资格、费用、最小申报数量和资金预算逻辑。模拟委托创建时仍会在资金事务中重新检查；页面快照不是成交保证。
- 每日备份压缩；释放原始日代表前，必须完整读取压缩件、核对清单和原件校验值，且对应同一个最新源文件。半成品或损坏文件不能替代原件，可以从保留源重试。清理每日压缩件时，损坏的新文件不占用有效保留名额。压缩和轮转共用备份锁。
- 停止新增重复的 workflow/snapshots 文件；数据库快照照常保留。存储预算是数据目录的观测和告警，不能保证全机占用永远低于30GB。历史文件不会因展示预算而自动获得删除授权。
- P01a 记录真实请求及拒绝原因，拦截不合法日线后继续候选来源；P02 允许无交易意义的候选集合变化发布，保留后续审计完善项。
- P01d 扩展差异化现金分红核验；P01e 按已核上市日期与板块判断价格跳断，补齐现有名单的三条上市日期。适用于当前滚动研究窗口，不用早年创业板上市第六日复原历史20%交易制度。
- R1及个股趋势门的替换默认关闭。两端同版配对、原生管理员回执确认 exposure_regime=R1 后才启用。状态缺失/过期只限制新买入，不凭未知状态强卖。强制减仓按全部持仓预先分配额度，不向可卖标的转嫁不可卖部分。

## 发布和回退

先云端后本机；核对版本、code、build_id、模型最小请求和随后十分钟同步。不得热替换运行中的本机代码，不改模拟本金、市场范围或硬风控；SEC保持暂停、只研究名单另行办理。

原版补丁和独立反例保留在第四轮回执；P2/P3不冒充已修复。启用R1前必须重新取得权威账户的实际仓位，不能沿用旧检查。管理员审批机制不删除、不伪造回执。

回退前先处理强制减仓回合的未终结委托，并用仍识别研究隔离锁及回合归属的代码确认结果。未知委托保留核对，不能直接降到不识别这些保护的旧执行程序。已启用research_only持久锁时继续遵循0.22.8说明。压缩备份和业务数据库保留；恢复账本属于另一项操作，不由代码回退覆盖。
