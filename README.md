## 动态新闻板块

首页新增独立动态板块；原watchlist的六小时研究、分钟执行与信号规则保持。动态新闻每30分钟采集、筛选及研究，显示事件证据、候选标的、历史反应和未满足条件。两条线路共用一份模拟底池，按线路独立管理计划、委托和持仓；同股敞口和挂单占用合并核算，动态不得覆盖或卖出观察栏仓位。

动态数据覆盖主要全球媒体与央行、政府等官方来源，支持有界历史补采。历史补采不计入前向验证胜率；只有实际积累的独立前向样本和其他门槛通过后才执行模拟入场。支持现有规则范围内的普通A股、美股和四种固定资产；其他主题可作为新闻传导背景。动态独立暂停按钮不会停止已有动态持仓的退出管理。细节、默认门槛与验收见[动态新闻规格](docs/iterations/dynamic-news.md)。

## 页面与协作

- 首页汇总所有自选股的模拟持仓、报价及时间、买入区间、卖出与止损参考；点击名称进入固定个股网址。每股增加一至两句研究判断与当前等待条件，分别说明资料、趋势、事件、价格区间及休市状态。
- 个股页展示当前判断、关键证据、六个可展开研究维度、持仓与盈亏、资料缺口和完整可翻页成交/委托/买卖依据。每股只保留一份最近检查状态，已有委托显示已成交与剩余股数，实际阻挡原因优先展示。旧研究标明整理来源，新研究生成六项独立分析。
- 首次打开设置 Admin / Guest 两个不同密码（至少12字符）。Guest 只读并可提交意见；Admin 可运行任务、改设置，在私有收件箱查看和处理全部意见。密码重设及权限说明见 [协作与登录](docs/COLLABORATION.md)。
- 意见绑定股票和研究版本；只供人工审核，不进入模型证据、不直接修改策略。云端通过 HTTPS 登录访问；研究任务及策略写入由本地研究端管理。

## 已实现的工作流

- 每天00:00/06:00/12:00/18:00（每6小时）抓取公开研究行情、完整日线、公司公告及部分官方新闻正文，也自动导入inbox中有元数据的自有研报。每股就绪后开始研究。
- 原文哈希存档、就绪时间、版本和修订关系、按证券与可得时间过滤的FTS5检索、不可变快照与必查资料覆盖。快照不含复盘经验，只含用户批准并上线的研究规则。现有0.1数据库做增量迁移；未知历史就绪时间采用保守值。
- 每股增量研究：成功后记录已读片段，下次只送新增、修订或未读积压，沿用上次观点和可追溯历史摘录。失败不推进；大报告分轮接续，迟到资料不会因发布日期较早被跳过。
- 重要公司行为、风险公告和定期报告优先补取正文；识别带公司名前缀的报告，每股每轮默认补取4份，已取得正文不占补取额度，另有1份修订复查额度。研究先读报告关键经营与风险段落，其余内容继续分轮读取。
- 公司财务底稿保存近16个报告期的财务指标、资产负债与现金流量表，提供近八季及三年对照；累计与单季分开，保留单位、披露时间、原始响应及版本。缺失不填零，亏损不计算市盈率；没有一致预期或估值历史时明确无法判断价格反映程度。
- 量价研究加入5/20/60日收益、量能、波动、回撤，以及沪深300和业务参考股篮子的同期比较。参考篮子不是官方行业指数；本轮对照获取失败时，可以复用截至同一完整交易日且区间、复权口径可比的最新历史数据，并标明原获取时间；日期或口径不一致时保留缺口，抓取失败仍独立记录。
- 联合国、商务部与已有官方新闻共同进入共享资料库；主研究只纳入直接公司关联或业务匹配的信息，新闻证据预算默认不超过资料包上限的15%。弱关联新闻和重复报道留在可展开背景资料中，公共来源故障集中显示，不重复打断每股判断。
- 订阅模型输出研究及原文引用，程序验证证券和引文；未复权技术指标推导模拟买卖区间。计划有版本、激活时刻、有效期与否决条件。
- 交易日连续竞价时段每分钟按最新有效策略检查买卖，分钟执行不调用大模型：价格进入区间且研究、公告等条件通过时申请买入；已有仓位触发退出或止损条件时申请卖出，程序再核验资金、持仓和委托。资金按账户事务预留，按后续报价保守分批撮合，支持T+1、费用、唯一意图和过期委托。独立成本止损可在研究过期时生成仅减仓保护计划。
- 仅实际提交委托时保存买卖依据及当时输入，成交继续逐笔保存；无操作及未通过检查的尝试只覆盖当前状态，不累积交易历史或完整盘面快照。调度保留少量去重和运行状态。既有历史数据不删除，旧的无操作记录不再出现在交易列表或新复盘中。
- 每天19:30按固定前24小时窗口复盘实际委托、跨窗口订单、成交费用和关联的当时输入；注明无操作检查不逐次保存，不据此推断漏检或错过机会。晚到回报保留修订。复盘同时运行程序一致性检查；发现按类别登记为工程问题或提案草稿，不直接进入研究。
- 首页以自选股总览为中心，持仓明细与上次买卖效果可展开；完整研究、资料和历史记录在个股页，设置和运行详情在管理员专页。
- 每股报告首先回答当前倾向、最多三条核心证据、价格反映程度、等待触发与推翻条件；底稿、完整分析、一般待读资料及背景新闻展开查看。相关失败项位于股票底部，按股票、处理步骤、具体文件独立记录；对应资料后续成功后自动消失，原始历史记录保留。有限采集范围不等于抓取失败。
- “当前交易限制”按实际计划列出原因、在等什么、用户可做什么、解除条件和原文链接；区分未取得正文、正文待读与已补齐待重研。分红关键词说明为待核验事项，不称作已确认重大利空；已支持证据与规则通过后自动解除纯现金分红事项；其他事件列出缺失证据或尚缺规则，不自动推断风险消失。
- 页面操作会自动获取当前连接凭据，后台重启后不用手动刷新；提交、等待、完成及失败都有就近中文反馈。重复操作合并为同一任务，网络响应不确定时不自动重复提交。
- 账户区显示现金与逐股市值占比、持股/可卖数量、报价时点、浮动损益；最近买入与最近卖出分别按委托合并成交，展示费用和实际结果。没有成交时明确显示暂无效果。
- 可查看阻断原因、队列、来源、成交、复盘与证据，编辑自选股和暂停新定时任务。
- 唯一服务锁、持久化任务队列、独立采集/Slot/复盘工作线程、漏过Slot不追单、重启恢复、数据库备份，以及macOS登录自启动管理。

- 独立行情与公告刷新（当前10秒/120秒）；逐股有界补取及研究重试；AI负责六小时研究；分钟执行直接核对有效策略，不反复消耗订阅额度。具体影响、操作和EMT行情待确认项见 [失败恢复与补资料说明](docs/RECOVERY.md)。

## 当前能力边界

- 手动证据检索使用FTS5；自动研究按股票、业务相关性和版本选择未读片段，沿用有限历史摘录及必要财务基准。语义向量、OCR、一致盈利预期、完整历史估值与所有来源的授权新闻/券商研报尚未接入。自动公司报告不等同于券商研报。
- 财务来自公开整理数据，已做证券、币种、期间、数值和资产负债勾稽检查，尚非逐项人工对账；修订历史不能当作过去时点已知数据。当前迈威生物的公开日线只提供未复权序列，系统不据此计算跨口径相对强弱。
- 严重风险、公司行为待核验、关键资料缺失或未完成审阅会阻止新增交易，一般程序性资料和弱关联背景不再一律阻断。模型不能自行解除确定性限制。
- 价位策略是可复现的技术模拟基线，没有经过收益验证（0.15.0 起可用 `./agent backtest` 离线回测、用对照账本前向比较）；不是需求文档中完整基本面评分策略的实现。当前新计划的买入区间为20日均价±2%（配置`paper_entry_band_bps: 200`，旧配置缺省100）；原趋势、资料、事件、止损与仓位条件继续生效。每份计划保存自身参数，旧研究不会追溯改价。排查依据见 [买入限制与首页摘要](docs/iterations/entry-status.md)。
- 公开报价不是券商执行行情；没有真实盘口队列/成交容量模型。支持沪深主板、创业板和科创板的普通股票（不含北交所、B股，以及ST、退市整理和上市初期名称带N、C前缀的股票）；科创板买入至少200股。交易日历按 `ashare/data/cn_a_calendar.json` 已录入的年份执行（当前至2026年），未录入年份不执行交易Slot，每年11月起待办提醒录入次年休市安排。
- 提取阈值与留存阶梯仍按用户确认的15/12、20/15、30/20、40/30……万元执行模拟资金规则；收益可以继续投资。实际资金转出未接入。
- 配置不允许实盘和付费模型后备。模型在云端通过现有订阅推理，本机保存数据库与运行状态。
- 软件测试与一次运行验证不代表20个交易日稳定性验收或投资策略有效性。

## 0.6.1 全球宏观动态板块

动态板块先研究世界宏观事件，再单独核验可执行计划。新闻入口与A股目录解耦；涵盖央行、通胀增长、地缘贸易、能源商品，以及全球科技医疗政策。全球事件展示影响市场、传导机制、预期差、反证及逐字引文。

新增美联储、欧洲央行、英国央行、日本央行及EIA官方RSS，使用FRED公开历史指标观察事件后变化。来源失败、发布延迟和未接入的历史序列明确呈现；历史指标变化不等同交易回测。当前模拟执行适配仍为普通沪深主板，全球研究不因执行支持范围被过滤。观察栏、板块切换、资金及交易归属逻辑沿用原实现。
